Base64

Base64 是一种基于 64 个可打印字符来表示二进制数据的编码方式。常用于在 HTTP 环境下传递较长的标识信息。

编码过程：每 3 个字节 → 4 个 Base64 字符。不足 3 字节时用 = 填充。

字符集：A-Z、a-z、0-9、+、/

Safe62

Safe62 是一种 URL 安全的 Base62 编码方案，使用 62 个字符（0-9、A-Z、a-z），不包含 +、/、= 等特殊字符。

适用于 URL 参数、文件名等需要避免特殊字符的场景。

编码流程：原始字节 → 分块（每 256 字节）→ BigInt 进制转换 → Base62 字符串

Basecoder

Basecoder 是本项目使用的组合编码方案，流程如下：

编码：文本 → UTF-8 字节 → Base64 → Safe62

解码：Safe62 → Base64 → UTF-8 字节 → 文本

先用 Base64 将任意文本转为 ASCII 安全字符串，再用 Safe62 进一步编码为 URL 安全格式。
